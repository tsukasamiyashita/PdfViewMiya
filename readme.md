# PdfEditMiya

起動と描画の高速化に特化し、スクロール遅延ロード（Lazy Loading）を採用したデスクトップPDFビューアです。

## 主な機能
* **ドラッグ＆ドロップ対応**: エクスプローラーからPDFファイルを画面にドラッグ＆ドロップして即座に開くことができます。エクスプローラーでのファイルの関連付けによる直接起動にも対応しています。
* **マウスホイールによるページ切り替え**: 単一ページ表示モード時、ページ最上部/最下部でのホイール操作で前後のページへジャンプできます。
* **A3・A4混在の自動サイズ調整**: 単一ページ表示時、ページの物理サイズに合わせて自動ズームします。
* **高度なスクロール操作**: 
  * `Ctrl` + ホイール: ズーム
  * `Shift` + ホイール: 横スクロール
  * `上下矢印キー`: 高速スクロール
* **ドラッグ移動（パン機能）**: マウスの左クリックドラッグで直感的に画面を移動できます。
* **その他**: 目次表示機能、ページ回転、各種ズーム設定、印刷などを搭載しています。
